# AI Interview Coach v2

An additional version of the interview preparation app, with a React/Vite frontend and FastAPI backend.

## Run locally

- Frontend: install dependencies in `frontend/`, then run `npm run dev`.
- Backend: install `backend/requirements.txt`; set `GEMINI_API_KEY` as an environment variable, then run the FastAPI app with Uvicorn.

Keep credentials in environment variables or an untracked local `.env` file.
